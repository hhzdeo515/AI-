在 `E:\AI智能助手\` 下新建 `assistant-lite\`，替代旧 `dify-assistant\`（Dify Chatflow + Docker，太重）。

### 架构核心思路
把"问答型"和"主动提醒型"统一成同一条 `event → orchestrator → agent → Reply` 事件流，
区别只在 Agent 内部有没有状态机。全项目只有 `Task` / `Reply` 两个数据结构。

### 踩坑记录
1. **清华 PyPI 镜像没有 `dashscope` 包**（`from versions: none`），官方源有（1.27.6）。
   装依赖要用 `-i https://pypi.org/simple`。
2. **`importlib.util.find_spec` 在父包不存在时抛 `ModuleNotFoundError` 而非返回 None**，
   用它做"模块是否存在"判断必须 try/except。
3. **粘性场景规则会吞掉其它场景的输入**：会议进行中，`计算 (18+24)*3` 被当成会议内容。
   修正：路由顺序必须是 事件 → 显式场景 → **关键词** → **粘性** → LLM。
   已加回归测试 `test_sticky_does_not_swallow_other_scenes`。
4. **浮点精度**：`120/(1+0.2)` 结果是 `99.99999999999999`，断言要带容差。
