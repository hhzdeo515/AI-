# Next.js 与持久任务升级验收

本次交付：Next.js React 前端、Flask/LangGraph 后端、SQLite 持久任务、单进程容器部署。没有修改原有用户数据库，没有将本机用户资料或模型凭据带入测试环境。

## 已验证

- Windows Python 回归：526 passed，172 subtests passed。
- Linux 容器中安装生产依赖后运行同一 Python 回归：526 passed，172 subtests passed。
- 原有 Node.js 交互测试全部通过。
- Next.js：19 项测试、TypeScript 检查、生产静态构建全部通过。
- 独立审查发现的检查点覆盖、失败结果无法重试、历史会话误接续、提交与历史切换竞争均已修复并复审。
- 浏览器实测：访问口令登录、算术请求得到 126、刷新恢复原结果、历史查询与 Markdown 下载、合成参考资料导入和选用、戒指方向键及确认切换、390px 窄屏布局。控制台没有应用错误。
- 最终 Docker 镜像：登录页、Next.js 页面与静态资源、健康检查、未登录接口拦截、Cookie、退出登录检查通过。
- 容器内实际提交算术任务，同 request_id 重复提交只保留一条任务；停止并重建容器后挂载同一测试卷，任务、结果与场景仍可读取。

## 部署边界

以上是隔离环境验证，不代表云端已经上线。测试没有使用真实用户内容，没有调用收费模型；相机、录音权限与真实设备表现还需在最终 HTTPS 地址确认。

当前没有提供可连接的云端 Python 托管环境、固定 HTTPS 后端地址及部署凭据。已提供 Docker、Compose、Render 模板、Vercel 前端代理示例、备份和线上检查脚本。完整部署步骤见[部署说明](部署.md)。

Vercel 导入新版前端时使用 frontend 根目录、Next.js 预设和 master 生产分支。只有配好云后端代理并通过实际 HTTPS 检查，才算完整应用已部署。
