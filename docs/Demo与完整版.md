# Demo 与完整版

使用此前的原版 HTML、镜片布局与 3D 戒指界面，不再发布 Next.js 工作台。Vercel 当前发布 Demo；Docker 和默认本地开发运行完整版。选择发生在构建时，不能通过网址参数、按钮或接口失败自动切换。

| 项目 | Demo 演示版 | 完整版 |
| --- | --- | --- |
| 用途 | 展示眼镜、戒指和业务操作流程 | 真实处理题目、练习与会议 |
| 入口 | 打开网址直接进入工作空间；翻译接口使用独立口令 | 后端校验访问口令 |
| 题解与会议数据来源 | 预设题解、练习点评、会议样例 | Flask / LangGraph 与模型服务 |
| 题解、练习与会议处理 | 浏览器模拟进度，不发起模型 API 请求 | Python 持久任务与有限工作线程 |
| 实时翻译 | 浏览器识别语音，Vercel 翻译接口处理真实文本 | 浏览器识别语音，受口令保护的 Flask 翻译接口 |
| 地图与朝向 | IMU 模拟可用；配置高德密钥后启用镜片内地图、地点搜索与定位 | 相同功能，由 Flask 代理高德服务 |
| 图片和录音 | 仅本机预览，不上传、不持久保存 | 鉴权上传、处理、持久保存 |
| 记录 | 浏览器保存最近 50 条示例任务 | 后端持久卷，保留已有用户数据 |
| 资料库 | 本机文本、TXT / Markdown；不参与真实检索 | 后端 TXT / Markdown / DOCX 与检索 |
| 导出 | 本地生成 Markdown / TXT | 后端 Markdown / TXT / DOCX / PDF |
| 模型费用 | 不调用模型 | 取决于模型账号与用量 |

页面不再显示 Demo / 演示模式标识或重复说明，预设题目和结果标题保留“示例”名称。拍照解题、练习和会议中的输入或上传不会生成真实识别、转写、评分或纪要；会议的发言人修订只更新示例发言记录，不重写固定纪要要点。实时翻译会处理实际语音原文与文字。

## Demo 开发与发布

```sh
cd frontend
npm ci
npm run dev:demo
# 或静态构建：
npm run build:demo
```

Vercel 项目选择 `frontend` 根目录、Other 框架、生产分支 `master`、输出目录 `out`，并允许读取根目录以外的源码。已提交的 `frontend/vercel.json` 固定执行 `npm run build:demo`，从 `langgraph-app/lg_assistant/web` 导出原模板和静态资源。`frontend/api/translate.js` 是独立 Node.js 翻译函数，不需要 Python 后端或模型密钥；题解、练习与会议仍使用浏览器示例。当前生产地址为 https://ai-vert-theta-44.vercel.app/ 。

打开首页或 `/login/` 直接显示原版镜片与 3D 戒指，默认进入场景选择。保留拍照解题、持续练习、会议、逐题阅读、资料库、模型选择和戒指手势。Demo 专用适配器复用既有浏览器示例数据，输入和上传只触发预设示例结果，摄像头/麦克风仍需浏览器权限。归档结果可在资料库查看，导出支持 Markdown 和 TXT；云端语音播报只在完整版可用。

示例任务与文本资料沿用 `glasses.demo.data.v1`，已有记录保留，与完整版数据分开。刷新后直接打开原版场景选择，完成的示例结果在资料库查看。清空浏览器或换设备不会保留这些演示记录；需要清除时，可通过浏览器的网站数据管理删除当前站点数据。

Demo 没有服务端登录、题解/会议业务 API 或 `/health`。直接 HTTP 请求这些路径返回 404 是预期行为；浏览器里的原版脚本由 Demo 适配器处理。`/api/translate`、`/api/map-config`、`/api/amap-proxy` 和 `/_AMapService/` 使用真实函数，其他未知接口返回错误且不会请求后端。验证应检查原版镜片、3D 戒指、场景切换、翻译、IMU、资料与静态资源，不能用完整版健康检查判断 Demo 失败。

## 摄像头视野与光波导外观

眼镜镜片以第一人称画面作为背景，功能菜单、答案、翻译和地图叠加显示。初始背景是带有“模拟视野”标记的室内示意场景；点击“开启摄像头”并允许浏览器权限后，切换到本机摄像头实时画面。此预览不录制、不上传，不申请麦克风权限。摄像头不可用或权限被拒绝时继续显示模拟场景，并可重试。

拖动镜框或镜片空白区域可旋转眼镜，滚轮缩放范围为 70%–135%；双击空白区域或点击“复位”恢复初始视角。聚焦眼镜后也可用方向键旋转、加减号缩放、Home 复位。功能按钮保持点击操作，答案与表单区域保持正常滚动，浏览器捏合缩放不被拦截。手机支持拖动与加减按钮。

“光路示意”可开关入耦、镜片内反射路径与表面浮雕光栅出耦效果。光栅纹理和导光路径均为放大的视觉示意，不是物理光学求解；原有功能仍通过菜单和戒指操作。启用系统减少动态效果时，光路动画静止。

打开拍照解题会停止背景预览，将摄像头让给拍照窗口；结束后可手动重新开启实时视野。进入资料库、隐藏页面或关闭页面会释放摄像头；尚未完成的权限请求不会在返回后意外开启预览。

## 横向功能选择与语音选择

主功能和功能内操作均采用横向卡片。鼠标或手指在卡片区域左右拖动，松开后停在最近的选项；左滑切换到后一个，右滑切换到前一个，首尾循环。点击卡片确认具体操作，也可使用上一项 / 下一项按钮、方向键或戒指。卡片滑动只切换选项，不触发功能或转动眼镜；镜框拖动和滚轮缩放继续可用。

在菜单中点击“语音选择”才开始聆听一次，支持“拍照解题 / 拍照 / 解题”“会议纪要 / 会议”“实时翻译 / 翻译”“地图 / 导航”，也可说“请帮我打开地图”等带前缀的指令。识别主功能名称后进入该功能的操作菜单；在操作菜单中也能说具体选项名称进行选中，再点击确认。语音不会自行开始拍照、会议录音、打开本地文件或提交 AI 请求。“上一个”“下一个”“返回主菜单”可用于菜单导航。

语音选择使用浏览器的 `SpeechRecognition` / `webkitSpeechRecognition`，需要 HTTPS、兼容浏览器、麦克风权限，部分浏览器还依赖厂商在线识别服务。识别到完整指令后停止，12 秒没有完成也会自动结束；不识别含否定词、多个功能或不匹配的指令。再次点击、手动切换或拖动菜单、离开菜单、隐藏页面和退出页面都会停止识别并忽略迟到的回调。不支持识别或权限被拒绝时，滑动与点击选择继续可用。语音选择只在菜单中提供，不与翻译语音识别或会议录音同时开启。

## 实时翻译与地图

镜片菜单新增实时翻译与地图，可用戒指选择控件、单击确认、长按返回。

- 翻译支持中文、英语、日语、韩语、法语、德语、西班牙语、葡萄牙语、意大利语、俄语、阿拉伯语、印地语、泰语、越南语、印尼语。语音识别由浏览器提供，麦克风仅在用户点击开始后开启；不支持语音识别时使用文字输入。完整语句按顺序翻译，返回或切换页面会停止识别并取消待处理请求。
- 译文来自 [MyMemory](https://mymemory.translated.net/doc/spec.php) 的真实服务，文本会发送给该服务；公共服务有日额度与网络限制，失败会显示提示。每个请求最多 500 UTF-8 字节，客户端自动拆分文字。翻译不依赖题解/会议的示例数据。
- Vercel 翻译接口需要私密 `TRANSLATION_ACCESS_TOKEN`，至少 24 字符，通过平台加密环境变量保存。生产缺少口令时拒绝翻译；首次请求提示输入口令，仅保存于当前浏览器会话，并以 Bearer 发送到同源翻译接口。当前账号持有者的口令保存在 Git 忽略且限制读取权限的 `.deploy-validation/translation-access.env`，不要将该文件提交、上传或打印到日志。完整版继续使用原有全局访问口令和 Cookie。
- 地图使用[高德 JS API 2.0](https://lbs.amap.com/api/javascript-api-v2/guide/abc/load)。当前用户尚无开发者密钥，镜片内地图显示待配置提示；可以打开高德官网搜索与查看坐标。配置后支持地点搜索、定位、缩放和朝向朝上。浏览器 GPS 的 WGS84 坐标经高德转换后用于镜片内地图，外部高德链接注明坐标类型。
- IMU 模拟立即可用：拖动罗盘、移动角度滑杆或使用方向键，显示 0–359° 与八个方位；“以当前方向为北”可校准。点击“读取设备方向”后才申请传感器权限，有可用绝对方向传感器时显示实际朝向，相对方向注明未校准。普通电脑没有方向传感器时回退到手动模拟，旋转电脑本身无法提供真实方位。返回、切换页面与隐藏页面会停止传感器和未完成请求。
- 高德私密配置为 `AMAP_JS_API_KEY` 与 `AMAP_SECURITY_JS_CODE`。安全密钥仅用于同源服务端代理，浏览器收到 JS API Key 和代理地址；生产接口复用翻译访问口令，SDK 使用短期 HttpOnly Cookie。尚未配置时 `/api/map-config` 返回 503，IMU 不受影响。高德控制台需配置实际 HTTPS 域名，设置方式见[安全密钥说明](https://lbs.amap.com/api/javascript-api-v2/guide/abc/jscode)。
- 地图与翻译需要联网；语音识别和真实方向感应的可用性取决于浏览器、语言及电脑传感器。手动 IMU 不依赖高德密钥。

## 完整版开发与发布

```sh
# 先按部署说明配置并运行 Python 后端
cd frontend
npm run dev
# 完整版静态构建，npm run build 同样默认完整版：
npm run build:full
```

`API_PROXY_TARGET` 只用于完整版开发代理，默认 `http://127.0.0.1:5000`。Dockerfile 显式执行 `build:full`；该构建保留原脚本的真实 API 请求，不注入 Demo 适配器。默认构建输出都在 `frontend/out`，构建另一个版本会替换该目录。Flask 首页与登录页始终返回原版模板，不再被历史 Next.js 导出覆盖。

完整版按 [部署说明](部署.md) 使用单进程、单实例、持久卷、HTTPS 和私密访问口令。当前尚未配置后端云端托管，Demo 上线不代表完整版已上线。

如以后单独在 Vercel 发布完整版前端，应使用独立 Vercel 项目与部署分支，在该分支用 `deploy/vercel.frontend.example.json` 替换前端配置并填入真实后端地址。不要覆盖当前 `master` 的 Demo 配置。
