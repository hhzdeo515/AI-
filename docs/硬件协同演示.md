# 电脑端硬件协同演示

入口：`http://127.0.0.1:8802/#hardware`，或左侧「硬件协同」。

只提供拍照解题、会议纪要两个业务场景。左侧为眼镜单镜片预览，右侧为虚拟戒指控制窗。

## 演示步骤

1. 场景入口：直接在戒指或右侧滑带上上下拖动，戒指本体保持稳定，「拍照解题／会议纪要」的选中项同步预览；左右拖动也可操作。松开后经模拟链路确认选中项，单击进入该场景的操作菜单；也可直接点击场景按钮。
2. 操作菜单：拖动实时移动选中项，每 44 像素一项，场景与操作菜单均首尾循环：第一项再上滑选中最后一项，最后一项再下滑回到第一项，连续拖动或反复滑动均可一直循环；松开确认选择，单击执行。解题菜单为「拍照解题／导入图片／查看上次答案／返回场景」，会议菜单为「生成会议纪要／导入录音／查看上次纪要／返回场景」。尚无素材或结果时会提示下一步。
3. 拍照解题：选择「导入图片」，导入 JPG / PNG / WebP（最多 20 MB）。图片只在本机预览，导入后自动选中「拍照解题」；再次单击确认，经模拟控制链路确认后提交原始图片至现有解题接口，保持原始分辨率。
4. 会议纪要：选择「导入录音」，导入会议音频（最多 32 MB），可在本机试听。导入后选中「生成会议纪要」，单击确认提交转写与纪要生成；这里处理已有录音，不是开启麦克风录音。
5. 实际 AI 返回正文后自动进入镜片内的 HUD 阅读层，解题原图保留在右侧。拖动时正文连续跟随移动，滚动量为拖动距离的两倍：向左／上向前读，向右／下向后读，到正文首尾停止。阅读进度与末尾提示同步反映实际位置。松开提交模拟导航；取消拖动或传输失败会恢复拖动前的位置。单击或键盘方向键仍按阅读区域高度的 72%（至少 80 像素）分段阅读。
6. 双击戒指或按 Esc 返回上一级：阅读层回操作菜单，操作菜单回场景入口。长按至少 0.7 秒后松开，直接回场景入口。「继续阅读」或 R 可重开当前场景已有结果。
7. 界面只保留眼镜、戒指及素材交互。缺少素材、文件无法读取或 AI 处理失败时，提示直接显示在镜片内；处理中的状态也在镜片内呈现。底部流程、重复反馈、操作记录和故障演示已移除。

文件只有在确认「拍照解题」或「生成会议纪要」时才提交到本项目后端及已配置模型服务。导入、选择菜单和阅读本身不调用 AI。不会自动打开摄像头、麦克风。

右侧戒指使用细窄圆润的 WebGL 金属模型，眼镜与戒指保持同页。默认拖动只操控菜单或正文，模型保持稳定；整个戒指按钮及右侧滑带均可拖动，滑带刻度与滑块跟随位移。超过 12 像素后按主要拖动方向进入连续操作；仅在「仅看旋转」模式中，模型两轴可完整旋转。菜单选择只在松开后经模拟链路提交，取消或传输失败恢复原选择。拖动松开不会追加单击。鼠标／触控单击等待 280 毫秒判定双击，双击返回不会先误触拍照。可选的「仅看旋转」只旋转模型，不改变菜单或正文；此时也可聚焦戒指后用方向键查看各面，点击「返回操控」恢复正常输入。切换旋转模式或离开页面会取消待判定的单击及进行中的拖动。

下方重复的六个操作按钮已移除；轻点确认、双击返回、长按回入口以及镜片内的「查看上次答案／纪要」完整保留。

键盘：方向键移动选项或阅读位置，空格确认，Esc 返回一级，Home 回场景入口，R 继续阅读。原生按钮保留空格／Enter 激活；表单、音频控件及获得焦点的结果正文保留原生键盘行为。减少动态效果设置下，阅读跳转不使用平滑动画。

浏览器不支持 WebGL 时使用 CSS 戒指，保留原生按钮和指令操作。运行中丢失图形上下文会退出旋转查看、禁用旋转并切回 CSS 戒指；重新加载页面可尝试恢复模型。减少动态效果设置会停用模型缓动和状态脉冲；页面隐藏或离开硬件协同后停止模型动画。

## 模拟与真实边界

- 戒指、眼镜、传输延时及指令回执均为浏览器内模拟，没有蓝牙连接、硬件功耗或延迟测量。
- 拍照指令读取用户导入的原始图片，模拟眼镜快门采集；不是摄像头实拍。
- 解题、音频转写、纪要使用现有 `/api/chat/async`、`/api/task` 和 `/api/progress`，没有预设 AI 答案。未配置模型或请求失败时展示错误并保留素材。
- 演示按场景使用独立 session_id，避免混入原有会议或题目上下文。
- 页面不再提供模拟断连、故障注入或重置按钮；底层模拟器保留这些机制供代码测试使用。

## 代码与验证

- `hardware-engine.js`：`HardwareNavigation` 管理场景／动作／阅读层、选中项、首尾循环的菜单预览和有边界的正文滚动；模拟器提供事务式 `navigate`、连接状态、忙锁、故障与取消代次。
- `hardware.js`：本机素材预览、拖动时的菜单预览和连续阅读、取消或故障回滚、调用现有 AI 请求桥接。
- `smart-ring.js`：原生 WebGL 圆润戒指、连续拖动生命周期与独立旋转模式、键盘旋转、单击／双击互斥、长按识别，以及图形上下文丢失回退通知。
- `hardware.css`：曲面单镜片、金属戒指、随拖动变化的纵向滑带、上下文菜单及镜片内 HUD 结果；处理、快门与回显使用轻量动画，尊重减少动态效果设置，沿用现有石墨绿与薄荷绿视觉。
- `studio.css`：主界面的深色石墨与薄荷绿视觉、导航、表单及结果组件。
- `node tests/test_hardware.cjs`：成功、断连、超时、拒绝、切换、重复输入和重置取消。
- `node tests/test_hardware_navigation.cjs`：场景及动作选择、素材与结果条件、阅读方向、返回与入口、导航失败不提交状态；连续拖动的开始／移动／结束、正常滑动不旋转、独立旋转模式、菜单循环与正文滚动边界、取消、仅旋转模式、松开不追加单击，以及双击不先触发单击。
- `node tests/test_smart_ring.cjs`：手势、取消、重复点击抑制、旋转模式与键盘输入，以及图形上下文丢失通知、停止绘制和原生回退；材质外观与响应式布局另需浏览器目视验收。
- `python -m pytest tests -q`：现有主项目回归。

真机接入时需要新增真实设备传输适配器与采集实现，保持命令、执行结果和 UI 的职责边界；本版本不声称这些能力已接入。

当前主项目已移除锻炼页面、状态机、路由、健康档案功能及专属代码与测试。已有数据库及历史归档不清空。
